Welcome to the ultimate repository for Cisco Enterprise Networking certification preparation. 

This repository contains my comprehensive, structured study guides and configuration notes covering the entire journey from **CCNA (200-301)** to **CCNP (ENCOR 350-401, ENARSI 300-410)**, and ultimately **CCIE Enterprise Infrastructure**.

Whether you are just starting with networking fundamentals or preparing for your CCIE lab, this living document serves as a centralized "second brain" for all necessary protocols, configurations, and troubleshooting methodologies.

## ✨ Key Features

* **Comprehensive Coverage:** End-to-end knowledge base bridging the gap between basic routing/switching and advanced enterprise architecture.
* **Deep Technical Dives:** Focuses on underlying mechanics rather than just commands (e.g., precise ACL matching for OSPF using protocol 89, deep dives into BGP attributes, and STP/HSRP nuances).
* **Ready-to-Use Lab Configs:** Includes verified configuration snippets and topology notes tested in simulation environments.
* **Network Automation:** Integrates modern CCIE EI requirements, featuring Python scripts for automated device provisioning and data parsing.
* **Structured for PKM:** Optimized for Personal Knowledge Management (PKM) tools like Obsidian. Topics are modularly linked for easy navigation and review.
